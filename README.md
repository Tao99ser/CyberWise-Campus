# CyberWise Campus

Bilingual interactive educational web application about cybersecurity for university students.

## Run locally

Open `index.html` in a browser or use the VS Code Live Server extension.

## Publish

The project is fully static and can be published directly with GitHub Pages. Upload every file and folder while preserving the current structure, then configure Pages to deploy from the repository root.

## Project scope

- Five learning modules.
- Ten independent lesson screens.
- Spanish and English content.
- One interactive activity on every lesson screen.
- Responsive design and keyboard-accessible controls.
- Institutional sources and APA-style credits.

## Phase 3 improvements

- Consistent cybersecurity icons and stronger visual hierarchy.
- Four-step learning path on every lesson screen.
- Ten bilingual university-life scenarios with recommended responses.
- Explanatory feedback for correct and incorrect activity answers.
- Session-only results summary identifying mastered or review topics.
- Responsive images that preserve their original proportions.
- Subtle transitions with support for `prefers-reduced-motion`.

The project intentionally does not include user accounts, persistent progress storage, or a formal level-unlocking system because those features are outside the approved scope.
